Note markdown# Sichuan HaiJu Foreign-Expert Project Support

Sichuan host units introducing foreign experts; foreign-national route only, excluding Hong Kong/Macao/Taiwan alternatives.

**Verified foreign route:** 引进人才应为外籍人才 — https://kjc.njtc.edu.cn/info/1041/37981.htm

**Cycle:** 2027 call issued August2026; NJTC internal cutoff September16, 2026 closed. Province-wide deadline unavailable, not equated to host deadline.

**Eligibility:** Current host guidance: Chinese formal employee leads introduction; normally born on/after January1,1969; foreign talent must meet 2024 HaiJu measures. Base route only approved/filed expert-introduction bases. No current overall numeric people minimum established: host/foreign roles specified, detailed track guide not publicly retrieved.

**Application:** Project proposal, talent passport proof, budget by actual needs; salary requests employment/service contract or intent including salary and dates; base proof; signed/stamped approval, applicant commitment and track-specific attachments through Sichuan science portal.

**Deliverable:** Foreign-expert introduction project with research direction/technical goals and host accountability; same unit/same work hiring multiple talents must be one project.

**Attendance:** Actual Sichuan work/cooperation in2027; remote cooperation explicitly unsupported. Current minimum on-site duration unverified.

**Award:** 2027 call: base project CNY200k; flexible project CNY200k; long-hire project CNY500k, each upfront support for January–December2027; no remote cooperation.

**Costs and conditions:** Budget subject to Sichuan high-end talent fund rules2021No55; salary contract proof mandatory. Exact eligible travel/equipment/tax/matching/clawback not read. 2025 two-track staffing and funding rules are historical and not transferred to2027.
