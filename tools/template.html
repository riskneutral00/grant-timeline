How to read this directory

All potential fits is the default catalogue, with no time cutoff. Active intakes means recorded as open, upcoming or rolling. Confirm eligibility on the official page. “Solo allowed” uses recorded team requirements; unspecified team sizes are not included.

Expired rounds remain as planning entries for the next year. Projected timing is explicitly an estimate from the previous round; it is not a confirmed deadline or proof that a new call will happen. Announced future programs remain visible regardless of how far ahead they are.

Only civilian software opportunities are included. Check registration, ownership, residency and exact cutoff times before applying. Record review dates can include historical research; the program description explains any uncertainty.
