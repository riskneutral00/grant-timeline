How to read this directory

Available means recorded as open, upcoming or rolling and flagged as a potential fit. Confirm eligibility on the official page. “Solo allowed” uses recorded team requirements; unspecified team sizes are not included.

Closed programs remain for reference. A closed program without a deadline has no verified active intake. Upcoming programs without a date have an announced future intake. Future rounds are never assumed.

Only civilian software opportunities are included. Check registration, ownership, residency and exact cutoff times before applying. Record review dates can include historical research; the program description explains any uncertainty.
